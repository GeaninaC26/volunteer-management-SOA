Volunteer Management System - Service-Oriented Architecture

About This Documentation

This collection of UML diagrams provides comprehensive documentation for the Volunteer Management System, a microservices-based application built with Service-Oriented Architecture (SOA) principles. The system manages volunteer recruitment campaigns, candidates, interviews, and volunteer assignments.

Technologies: ASP.NET Core 8.0, Vue.js, RabbitMQ, Apache Kafka, PostgreSQL, SignalR, Docker

Architecture Patterns

  • CQRS: Command Query Responsibility Segregation in API Gateway
  • Event-Driven Architecture: Kafka for asynchronous event distribution
  • Service-Oriented Architecture: Microservices with clear boundaries
  • RPC Pattern: Synchronous communication via RabbitMQ
  • Microfrontends: Module Federation for independent frontend deployment
